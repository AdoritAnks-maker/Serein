# nith-chat-app 
A real-time college chat application built for students of NITH (National Institute of Technology Hamirpur).

---

## 📌 About the Project

This is a full-stack web application where students can:
- Create an account and log in securely
- Join different college chat rooms (CSE, ECE, Hostel, General)
- Send and receive messages in real time
- Stay connected with classmates easily

---

## ⚙️ Features

- 🔐 User Authentication (Signup/Login using JWT)
- 💬 Real-time Chat using Socket.io
- 🏫 Multiple College Chat Rooms
- 🧑 User Profiles (username, email, branch)
- 📦 MongoDB Database Integration
- 📱 Responsive Frontend UI

---

## 🛠️ Tech Stack

**Frontend:**
- HTML
- CSS
- JavaScript

**Backend:**
- Node.js
- Express.js

**Database:**
- MongoDB + Mongoose

**Real-time Communication:**
- Socket.io
